READ-ONLY ARCADIUM ROUTE COLLECTION
Extract this small ZIP and open COLLECT_ARCADIUM_ROUTES.html in Chrome or Edge.
Click Choose Arcadium_OS_COMPACT & collect, and select your existing OS folder.
It downloads ARCADIUM_ROUTE_DIAGNOSTIC.json. Attach that JSON to the chat.

This is a diagnostic collector, not another game installer. It only reads 12 named Python source files and selected game catalogue URL fields. Missing files are reported. It does not alter the chosen directory, execute the Python files, change Windows settings, or send network requests. Source code is included in the output; review before sharing. User/player records and general settings are not exported.

The uploaded server composes additional Worm Riders, dice relay and Hexwood wrappers outside the uploaded bridge. Bridge-only tests did not reproduce those versions. The running server returned HTTP 404 even for the V2 staged connection page, so V2 is not a verified solution for this installation. This collector gathers the remaining source needed to trace that failure without manually finding each file.
