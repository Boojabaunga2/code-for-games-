ARCADIUM · Collect route diagnostics

This reads the server, route handlers and shared-host source files needed to trace the failed game connection. It downloads one diagnostic file for you to attach to our chat.

It does not write to your Arcadium folder, install games, start a program, contact Microsoft, or change Windows settings. It makes no network requests. The file contains source code; review it before sharing.

Open in Chrome or Edge on your Arcadium PC.
