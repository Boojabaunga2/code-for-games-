# Arcadium: Haunt & Seek

Complete playable PC build: six hunters, five castles, nine connected rooms per castle, 90-second hunts, Ghost Captains and six personal Mini Vibe trackers.

Download ARCADIUM_HAUNT_AND_SEEK_V1.zip. Extract the whole archive, close the existing Arcadium server console, then double-click START_HAUNT_SEEK.py and select the existing Arcadium_OS_COMPACT folder once. Requires the existing Python/shared-controller Arcadium setup. Use this launcher for this game; existing startup shortcuts remain unchanged. No new APK.

Only this game and its catalogue entry are installed, with backups. The existing OS server and controller receiver are loaded normally with an additional in-memory broker. Other game files and pairing are not replaced.

Keep Windows protection enabled; a clean runner scan does not establish that a recipient detection is false.
