# Barrel Bash / game files only

The V3 ZIP contains only the Barrel Bash web game, artwork, readme and checksums. No Windows installer, Python scripts, batch/PowerShell files, server patches or APKs.

Return to Arcadium and wait 10 seconds for the Mini Vibes to reach Command Deck. Extract the ZIP. Copy its games folder into the existing Arcadium_OS_COMPACT folder and replace only the Barrel Bash game files. Refresh Arcadium with Ctrl+F5 and launch Barrel Bash. Do not use Import Game, which would create a duplicate.

This uses the original Barrel Bash state relay present in the earlier supplied OS, or the newer shared frame relay if already installed. If the current OS no longer contains either relay, a files-only update cannot add one. Other game folders, OS startup, server code, pairing and the installed Mini Vibe app remain unchanged.

V1 and V2 installer packages remain withdrawn after recipient antivirus reports. Removing installers is a material delivery change, not a determination that prior alerts were false positives. Keep protection enabled and leave any flagged download blocked.
