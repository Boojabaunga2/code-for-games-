# Barrel Bash V2 / installer revision

Extract the complete V2 ZIP, run START_INSTALL.cmd, select the existing Arcadium_OS_COMPACT folder, and restart Windows once. Requires the normal installed Python launcher (py), Python 3.9+ and Tkinter. No new APK.

V2 removes interpreter discovery, inline preflight commands and dynamic code compilation. It adds a standard adapter registration without rewriting the existing bridge function. Original game/controls/art bytes remain unchanged; earlier game handlers, Home and pairing are preserved.

V1 was withdrawn after the recipient reported an antivirus alert. Prior Windows runner scans did not reproduce that alert. Independent signature, script-member Defender and Internet attachment checks do not establish a false positive, guarantee client acceptance or constitute a manual Microsoft verdict.
