# Trick motion mockup — for design review

A standalone animation study, not a game update or live six-player match. It shows proposed kickflip, heelflip, double flip, backflip, frontflip, 720 spin, indy grab and varial flip motion. Board flips use a separately animated board; body flips keep rider/board together. The clip is normal-speed browser capture. The released game and controls remain unchanged pending user review, following the user’s mockup-first preference.

Source is included as a standalone HTML/canvas prototype with the existing game artwork. No Android app replacement or game installation is provided in this preview.
