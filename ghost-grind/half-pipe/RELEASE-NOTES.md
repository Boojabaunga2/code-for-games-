# Ghost Grind: Half-Pipe Havoc

Rebuilt for Android Home Vibe around one shared U-shaped wooden ramp. All six skaters ride together in the same arena with a fixed camera. Pump through the bottom, launch aerials from either wall, perform flips/spins/grabs and land to bank combos. Steer across the width and softly bump rivals. Five 90-second rounds, one new playable ghost per round, one surviving champion.

Download Ghost-Grind-Half-Pipe-Home-Vibe.zip and leave it compressed. On the tablet: Settings / Console settings → Manage games (ADMIN) → Add a game from ZIP. Select the ZIP and open the new Half-Pipe entry. Connect all six phones using Connect Players on the same Wi-Fi. No replacement Android APK or phone APK is needed.

The game reads the existing tablet input bridge directly and works under the imported UUID. Older launchers use their existing default imported-game icon; the new half-pipe cover is visible inside the game. The source integration preserves all 49 older catalogue entries and updates Ghost Grind in slot 50.

Controls: hold A/↓ to pump while descending/through flat; in air B kickflip, X heelflip, Y 360 spin, L indy grab, R melon grab. Left/right steers across the ramp. B brakes on the wood. Ghosts use ↓ to pump, A to haunt and L/R to target. Tricks must complete before re-entry; unfinished combos bail. Disconnects freeze the match; reconnects preserve manual pauses.
