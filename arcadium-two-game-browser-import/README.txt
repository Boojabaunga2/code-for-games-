ARCADIUM TWO-GAME BROWSER IMPORT
Extract this ZIP. Open OPEN_GAME_IMPORT.html in desktop Edge or Chrome on your Arcadium PC.
Start your existing Arcadium launcher first, on port 8787. Click Choose OS folder & import and choose Arcadium_OS_COMPACT.
Both games are selected. The importer saves backups, checks the running shared host, then updates only the selected catalogue entries.
No downloaded CMD/EXE/Python launcher is used. Windows settings and root server/receiver/pairing files are unchanged.
If your existing launcher does not expose the shared game host, import stops and restores staged files. This package cannot add that server capability.
Restore: click Restore backup and paste the backup path printed during import. Later changed game files stop restoration for manual review.
Source is included. All web assets and their SHA-256 checksums are embedded in the HTML. Physical Mini Vibes and your Windows folder picker require a live test.
Ghostshot is adapted from the supplied V3 package to the existing generic Arcadium live-host protocol. Its custom server patch and Windows launchers are excluded.
