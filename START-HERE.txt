Home Vibe browser-host validation build

Requires Node 24 on a separate server for local hosting. Extract this ZIP and run npm start in the folder containing package.json. Then open http://SERVER-LAN-IP:8789 from your tablet and phones.

The hosted online edition uses a website instead and requires internet. A tablet running Chrome alone cannot accept incoming LAN connections.
